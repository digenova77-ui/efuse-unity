# Public surface — company first

## What this repository is

**Entity framing (public):** DualisCapax / Unity measure software and documentation.  
**This repo:** reference implementation of fuel + seal logic (`eFuse` under empty-center rules).

What the company “has to do with” anything is **only what a stranger can verify**:

- public code and docs in this repository  
- public website copy the operator chooses to publish  
- public registries (corporate, MSB, securities, etc.) **if and when** filings exist  
- behaviour under Gate A (law of the land)

No private biography is required to test the measure.  
No personal name is part of the seal.

Generate nothing here that pretends to open bank accounts or bind third parties.

## Irreversible upload rule

Everything published to the website or public git history is treated as a **permanent mark**.

- Prefer dead link over hollow “live pay”
- Prefer company + registry facts over personal narrative
- Prefer Gate A evidence over Gate B poetry

## Agent / automation bound

Automation may draft and test. It does not:

- log into bank or portal accounts  
- use credentials  
- open accounts  
- act as a natural person customer  

Only the human operator opens accounts and completes true KYC.

## Findable facts only

Do not assert structure (foreign entities, bonds, registrations) unless the reader can confirm them through ordinary public means.  
If unconfirmed → do not upload.
